# Safety and provenance

- Reference images need a consent choice: my own, with consent, or fictional. A shot started from your own image carries the same rule, so it takes a photo of you or of someone who agreed. Do not upload people who have not agreed. Do not use the studio for deception. Receipts mark every output as AI-generated.
- Output is for lawful, safe-for-work use. A plain content guard refuses prompts that ask for explicit sexual content, graphic gore or self-harm, before anything reaches a model. It is a good-faith filter. It is not moderation. It cannot recognise a real person's name, so characters must be invented or consented to.
- A face or a person goes into a swap only from a Cast, where that consent choice is recorded. Edit with words' two swaps and Re-shoot's *Swap only the face* refuse to start without one. The content guard also refuses taking someone's clothes off or seeing through them, whatever the words around it. An edit, or a shot that starts from your own image, never puts a person in underwear, swimwear or lingerie (`openfield/engine/safety.py`, `_EDIT_NEVER` in `openfield/engine/rig.py`). Ordinary phrases such as "take off his hat" still pass.
- The bundled showcase uses fictional characters. The Re-shoot source is a clip rendered with LTX 2.5. No real person was filmed.
- The interface ships Barlow, Barlow Condensed (the same Barlow project and licence), Overpass Mono (SIL Open Font License 1.1) and a selection of Lucide icons (ISC). Their licences sit next to them in `openfield/web/fonts/` and `openfield/web/icons/`. The workflows are the official ComfyUI templates (MIT). See `openfield/workflows/LICENSE.workflow_templates`.
- Every picture in the interface (key art, sets, props, overlays, the marquee's letter board and two loops) was rendered with open-weights models, Qwen-Image 2.1 for the stills and LTX 2.5 for the loops, through the app's own audited templates. `openfield/web/art/manifest.json` records each file's prompt, seed, template, workflow hash, the model files the audit found and its hashes. The Lobby's credits carry "Built with Qwen".
- A Comfy Cloud key or a proxy token pasted into the Connect sheet is kept in the server process's memory. It is sent only to the address it was pasted for. It is never written to disk, logged, echoed in an error or put in a receipt. The remembered connection file holds the address, the optional ComfyUI address, the kind and a timestamp. It never holds the key. The Connect endpoints, like every other change, accept same-origin requests only.
- This project was built with an AI coding assistant (Claude Code) under human direction. The plan and the code had independent review passes.
