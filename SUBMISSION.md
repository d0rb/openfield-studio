# Open Source Higgsfield submission package

## Two-minute demo cut

1. 0:00–0:15 — OpenField landing screen and the six-stage rail.
2. 0:15–0:45 — Cinema Rig: choose 35mm, anamorphic, contre-jour, 360 orbit;
   compile the graph and show the anti-drift contract.
3. 0:45–1:20 — OpenJutsu: load a 4–15 second phone clip, add references,
   compile LTX guide graph, then show the synchronized before/after slider.
4. 1:20–1:42 — Soul ID: show the reference vault and the unavailable-safe SFace
   gate; demonstrate that an absent model never becomes a false match.
5. 1:42–2:00 — Show `comfy-sdk`, dry-run output, open-weights-only policy, the
   MIT repository, and the try-it URL.

## Claims we can prove

- API-format workflows are generated locally and can be submitted through the
  Comfy SDK boundary, private ComfyUI, or dry-run mode.
- Camera controls compile into explicit physical constraints instead of only
  appending a vague “cinematic” adjective.
- LTX, MiniMax H3, and Qwen paths are capability-gated by required node names.
- Partner Router models are blocked when open-weights-only mode is enabled.

## Claims we must not make without a live render

- That every fleet server has every custom node.
- That an untested LTX or H3 graph preserves audio on a particular install.
- That SFace is available unless both ONNX files are installed.
- That a live try-it endpoint is deployed.
